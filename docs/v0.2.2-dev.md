# v0.2.2 Dev確認

Devブランチ: `dev/v0.2.2`。本番のコード・DB・公開URLはこの更新では変更しません。

## 変更点

- 検索・お気に入り・ファン一覧は出現先の確認を中心にし、指数は詳細内の折りたたみに移しました。
- 最近のリスナーを「名前／最近のライブ観測／登録」の3列で表示します。名前はプロフィール詳細、矢印はその行の出現先を展開します。
- 算出できない投げ指数のカードを削除しました。取得済みのDJ別Spoonと自枠のSpoonは補足として残します。集計期間が未確認の数値から、新しいDJに投げる確率を作ることはできません。
- 背景・パネル・入力欄を紺色で分け、ライブは青緑、月間温度は紫、Spoonは黄で区別します。文字・入力欄・ボタンのサイズをスマホでも見直しました。
- リスナー検索の隣に時間帯分析を追加しました。自分の登録ファン、自枠の当月温度が確認できた人、その他の観測を7日／28日で比較できます。自枠での初観測日／以前にも観測した人への切り替えもできます。

検証: Pythonの全213テストが成功。認証付きHTTPサーバーのブラウザ確認191項目が320・390・1365pxで成功し、JavaScriptエラー・ページの横スクロールはありません。アカウントごとの集計範囲、キーボード展開、属性・期間・単位の切り替え、未取得・エラー時の表示をテストデータで確認しました。配布用wheelにもCSSとグラフ用JavaScriptが含まれることを確認しました。

## 時間帯分析の集計

ログインアカウントに登録された自分のSpoon数値IDのライブ観測だけを使います。他のアカウントのファン設定や、他DJのダッシュボードは含みません。

時間帯は日本時間です。1人を同じ日・同じ時間帯では1回だけ数え、時間帯グラフでは日ごとの人数を合算します。収集のたびに同じ人を加算する方式ではありません。期間全体の人数は重複を除いた人数で、時間帯グラフの合計とは単位が異なります。

グラフの既定は「1観測日あたりの人数」です。人数を確認できた日数で割り、部分取得だけで人数が不明だった日は分母に含めません。「延べ観測人数」へ切り替えられます。日ごとのヒートマップと数値表では重複を除いた人数・取得状態を確認できます。観測できた時間の偏りは残るため、来訪を予測する確率としては使いません。

ファンと月間温度の分類は重複します。そのため、この2系列を積み上げて合計人数とは表示しません。ファン一覧は現在の登録内容、月間温度は自DJの当月ランキングで確認できた正の温度を過去の観測へ照合します。観測当時にファンだったかどうかは判定しません。

未取得や部分取得で見つからない人を「温度0」「ファンではない」とは断定しません。「その他」は現在の登録ファン・取得済みの月間温度のどちらにも確認できていない人です。観測がない時間は未観測です。完全取得した空の一覧だけを観測人数0として扱います。部分取得で確認できた人数は下限です。

初観測は、保存済みの自枠の記録における初観測日を指します。Spoonでの新規ユーザー、実際の初訪問、連続滞在時間、現在の視聴状態とは異なります。表示した多い時間帯は取得済み記録の比較であり、将来の来訪予測ではありません。

グラフは保存済みデータの集計なので、専用の新しいSpoon収集コマンドは不要です。新しいライブ記録・当月温度が必要なら、既存の自動収集を使います。Devの収集は既定で停止しています。

## MacのDevで更新する

DevのWebが起動中なら、そのターミナルでCtrl+Cにより止めて更新します。

```bash
conda activate spoondev
cd ~/SpoonDev-dev
git fetch https://github.com/APLAquilone/SpoonDev.git dev/v0.2.2
git switch -c dev/v0.2.2 FETCH_HEAD
python -m pip install -e .
bash scripts/start-dev-mac.sh
```

既に同名ブランチがある場合は、取得後に `git switch dev/v0.2.2` と `git merge --ff-only FETCH_HEAD` を使います。未コミットの変更は先に保存してください。
Dev画面は `http://localhost:8081`、ログインはDev用アカウントです。更新後にブラウザを再読み込みします。

既存パスワード・紐付け・お気に入り・ファン設定を保持します。本番へDBをコピーしません。公開はDev確認後に別途行います。
